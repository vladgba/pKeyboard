# VKeyboard Backup Example

Example configuration and layout backup exported from VKeyboard.

- `config/` — `settings.txt`, `dict.dic`, `touchstats.stats`, and cleaned `learned.words` (`clipboard.pins` omitted for privacy).
- `layouts/` — custom keyboard layouts (`en.txt`, `uk.txt`, `123.txt`, `$numpad.txt`, `$autofill.txt`, `emoji.txt`, `$emoji*.txt`) and themes (`baseDark.ini`, `baseLight.ini`, `Blackul.ini`).
